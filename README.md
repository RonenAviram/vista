# Vista.AI

The public sales site for Vista.AI, an AI fundraising service for Israeli nonprofits: https://vistagrants.co.il

Static GitHub Pages site. `index.html` is the sales page; it also holds the demo (`fundraising-demo.html`, `fundraising-behind-scenes.html`) and the legal pages. The signup form posts to the app's `/api/lead` (repo `fundraising-agent`).
